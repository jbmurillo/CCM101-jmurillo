# AWS Research


## Brief Overview


Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. It offers many services for computing, storage, databases, networking, security, and other business needs (Amazon Web Services, n.d.-a).


## Global Infrastructure


AWS uses Regions and Availability Zones as part of its global infrastructure. Regions are separate geographic areas, while Availability Zones are isolated locations within a Region. This structure helps organizations build applications that are more available and reliable (Amazon Web Services, n.d.-b).


## Cloud Management Console


The AWS Management Console is a web-based interface used to access and manage AWS services and resources. Users can create, configure, and monitor their cloud resources through the console (Amazon Web Services, n.d.-c).


## Four Core Services


### 1. Amazon EC2


Amazon Elastic Compute Cloud (Amazon EC2) provides virtual computing resources that can be used to run applications and workloads in the cloud (Amazon Web Services, n.d.-a).


### 2. Amazon S3


Amazon Simple Storage Service (Amazon S3) is an object storage service used to store and retrieve data in the cloud (Amazon Web Services, n.d.-a).


### 3. Amazon RDS


Amazon Relational Database Service (Amazon RDS) is a managed relational database service that makes it easier to set up and manage databases (Amazon Web Services, n.d.-a).


### 4. Amazon VPC


Amazon Virtual Private Cloud (Amazon VPC) allows users to create an isolated virtual network for their AWS resources (Amazon Web Services, n.d.-a).


## Three Advantages


### 1. Wide Range of Services


AWS provides many services for different computing, storage, database, networking, and security needs (Amazon Web Services, n.d.-a).


### 2. Global Infrastructure


AWS has Regions and Availability Zones in different geographic locations. This allows organizations to deploy applications closer to their users and improve availability (Amazon Web Services, n.d.-b).


### 3. Scalability


AWS allows organizations to increase or decrease resources depending on their workload and business requirements.


## Typical Enterprise Use Cases


AWS can be used by enterprises to host websites and applications, store business data, run databases, and support different business workloads. Companies can select AWS services based on their technical and business requirements (Amazon Web Services, n.d.-a).
