# Reflection

This laboratory activity helped me understand the basic environment of cloud computing through the use of KillerCoda and Ubuntu Linux. I learned how to access a cloud-based Linux environment and create a new user account with the necessary permissions.

I also learned how to gather basic system information using Linux commands. I used commands such as whoami, pwd, hostname, cat /etc/os-release, uname -r, lscpu, free -h, and df -h. These commands helped me identify the Linux distribution, kernel version, CPU information, memory, and available disk space of the environment.

Another important lesson I learned was how to organize files and directories in Linux. Creating the required folders and Markdown files helped me understand how proper file organization is important when managing technical projects.

Lastly, I learned how GitHub can be used as a professional portfolio for storing laboratory activities, documentation, screenshots, and reflections. This activity showed me that cloud computing is not only about using cloud services but also about properly managing, documenting, and presenting technical work.

Overall, this laboratory activity improved my basic Linux, documentation, and GitHub skills. It also gave me a better understanding of the responsibilities and practices involved in working with cloud computing environments.
