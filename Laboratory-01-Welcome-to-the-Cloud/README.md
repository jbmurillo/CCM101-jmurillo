# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity introduces the basic Linux environment, system information gathering, file and directory management, and GitHub documentation practices.

## Objectives

- Access a cloud-based Linux environment using KillerCoda.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a professional GitHub repository.
- Document technical work using Markdown.

## Activities Performed

1. Accessed the Ubuntu Linux environment using KillerCoda.
2. Created a new Linux user account.
3. Logged in using the created user account.
4. Checked the username, working directory, and hostname.
5. Gathered basic Linux system information.
6. Created and organized files and directories.
7. Prepared the Cloud Computing portfolio repository.

## Linux Commands Used

- whoami
- pwd
- hostname
- cat /etc/os-release
- uname -r
- lscpu
- free -h
- df -h
- mkdir
- nano
- cat
- find

## Skills Learned

I learned how to navigate a Linux environment, create and manage user accounts, gather system information, organize files and directories, and document technical activities using Markdown.
